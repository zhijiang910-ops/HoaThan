## 1. CHIÊU F ("THIÊN CƯƠNG ĐẠP TINH CƯỚC") — HỐ ĐÁ NỨT 2.5D ÔM KHÍT ẤN ĐỒNG CỔ XOAY TRONG LÒNG HỐ
Tâm đặt tại trước mặt nhân vật: `cx = player.x + facingDir * 72`, `cy = player.y - 8`. Toàn bộ vẽ ở `Ground Decal Layer` (trên nền đất map, DƯỚI chân quái và nhân vật):

- **Tỷ lệ khóa cứng để 2 lớp khớp thành 1 khối duy nhất (RẤT QUAN TRỌNG):**
  * Vành hố đá `vfx_f_crater_ring.png` (đã có sẵn phối cảnh 2.5D nên **KHÔNG ép `scaleY` và KHÔNG xoay**): chiều rộng chuẩn `craterW = 390`, `craterH = craterW * (craterImg.naturalHeight / craterImg.naturalWidth)`.
  * Ấn đồng cổ `vfx_f_thien_cuong_tinh_luan.png` (nằm **GỌN BÊN TRONG lòng hố đá tối**, không đè lấp lên vành đá vỡ bên ngoài!): đường kính ngang chuẩn **`sealDiam = craterW * 0.53` (`~206px`)**, ép phối cảnh mặt đất `ctx.scale(1, 0.62)` rồi mới `ctx.rotate(angle)`! Với tỷ lệ `0.53` này, 12 mũi răng cưa đồng cổ vừa khít mép trong của vành đá vỡ 2.5D nhìn như một khối chạm khắc dưới lòng đất!
- **Diễn hoạt 3 giai đoạn đồng bộ (tổng `3.0s`, KHÔNG dùng ảnh nổ ngang cắt đáy):**
  1. **Dậm Cước Sập Hố (`0.0s -> 0.18s`):**
     - Rung camera nhẹ `4px` trong `0.12s` + hit-stop `2 frame`.
     - Cả vành hố đá `crater_ring` lẫn ấn `tinh_luan` cùng bung nhanh từ `scale = 0.25 -> 1.04 -> 1.00` theo `Cubic Ease-Out` (`alpha = 0.96`).
     - Thay cho ảnh nổ ngang cũ: tại khoảnh khắc `t = 0`, chỉ bắn **10 mảnh đá phiến nhỏ màu nâu tối (`#4A3C33` viền đen `#1C1512`, kích thước `4px - 7px`)** nảy văng thấp ra xung quanh trên mặt đất 2.5D + 4 hạt khói bụi xám nâu mờ (`vfx_soft_ghost_smoke_puff.png` nhuộm nâu xám, `alpha <= 0.30`) tản ngang sát mặt đất.
  2. **Ấn Đồng Cổ Xoay Trong Lòng Hố (`0.18s -> 2.60s`):**
     - Vành hố đá `crater_ring` đứng yên cố định trên mặt sàn (`scale = 1.0`, `alpha = 0.95`).
     - Chiếc ấn `tinh_luan` bên trong lòng hố xoay tròn trầm ổn (`angle += dt * 0.95`, `alpha = 0.95`), gây sát thương đốt âm khí theo giây.
  3. **Khép Hố Thu Ấn (`2.60s -> 3.00s`):**
     - Ấn `tinh_luan` bên trong xoáy thu nhỏ dần từ `scale = 1.0 -> 0.15` (`alpha -> 0`), đồng thời vành hố đá `crater_ring` mờ dần `alpha` từ `0.95 -> 0.0` trả lại nền đất sạch.

```js
function renderSkillFGround(ctx, craterImg, sealImg, cx, cy, elapsedSec, angleRad) {
  const totalDur = 3.0;
  if (elapsedSec < 0 || elapsedSec > totalDur) return;

  const craterBaseW = 390;
  const craterBaseH = (craterBaseW * craterImg.naturalHeight) / craterImg.naturalWidth;
  const sealBaseRadius = (craterBaseW * 0.53) * 0.5; // Lọt khít lòng hố đá!

  let craterScale = 1.0, sealScale = 1.0, craterAlpha = 0.95, sealAlpha = 0.95;
  if (elapsedSec < 0.18) {
    const p = elapsedSec / 0.18;
    const ease = 1 - Math.pow(1 - p, 3);
    const pop = p < 0.75 ? (0.25 + 0.79 * (p / 0.75)) : (1.04 - 0.04 * ((p - 0.75) / 0.25));
    craterScale = pop;
    sealScale = pop;
  } else if (elapsedSec > 2.60) {
    const p = (elapsedSec - 2.60) / 0.40;
    craterAlpha = 0.95 * (1 - p);
    sealAlpha = 0.95 * (1 - p);
    sealScale = 1.0 - 0.85 * (p * p);
  }

  // 1. Vẽ Vành Hố Đá Nứt 2.5D đứng cố định
  const cw = craterBaseW * craterScale;
  const ch = craterBaseH * craterScale;
  ctx.save();
  ctx.globalAlpha = Math.max(0, craterAlpha);
  ctx.drawImage(craterImg, cx - cw * 0.5, cy - ch * 0.5, cw, ch);
  ctx.restore();

  // 2. Vẽ Ấn Đồng Cổ Hổ Phù Bắc Đẩu xoay tròn gọn trong lòng hố đá
  const sr = sealBaseRadius * sealScale;
  ctx.save();
  ctx.globalAlpha = Math.max(0, sealAlpha);
  ctx.translate(cx, cy);
  ctx.scale(1, 0.62); // Khớp chuẩn độ dẹt 0.625 của lòng hố đá!
  ctx.rotate(angleRad);
  ctx.drawImage(sealImg, -sr, -sr, sr * 2, sr * 2);
  ctx.restore();
}
```

## 2. CHIÊU C ("TOÁI PHÁCH BÁT CỰC CHƯỞNG") — CHƯỞNG ẢNH ĐỒNG CỔ CHU SA U TỐI ĐỒNG BỘ ĐẠI CHIÊU X
- **Khóa cứng hướng mặt `lockedDir`** ngay khi bấm phím C suốt `1.0s` tung chiêu (tuyệt đối không cho auto-attack xoay lưng nhân vật sang trái-phải giữa chừng!).
- Xóa tia lửa nhọn đòn đấm thường trong chiêu C. Dùng duy nhất tấm `assets/vfx/vfx_c_single_palm.png` (bàn tay giáp đồng đỏ chu sa kéo khói đen & bùa cổ):
  * Trong 6 nhịp liên hoàn (`0.0s -> 0.70s`, mỗi `0.11s` 1 đợt): mỗi đợt phóng **2 bàn tay `vfx_c_single_palm.png`** (`width = 135px - 150px`, lệch độ cao `offsetY` xen kẽ `-28px` và `+14px`) từ trước ngực nhân vật lao thẳng tới trước `90px` theo hướng `lockedDir` trong `0.20s`, giữ `alpha = 0.95` trong `70%` đầu để nhìn rõ từng ngón tay giáp đồng và ấn sao Kim Cang trên lòng bàn tay!
