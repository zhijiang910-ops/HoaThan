# Khử Tà Diệt Ma 驅邪滅魔

Game hành động sinh tồn pixel art, một file `game/index.html` cùng `game/assets/`, chạy trên trình duyệt, ưu tiên điện thoại xoay ngang. Repo riêng tư, có asset mua giấy phép.

- `CLAUDE.md`: bàn giao đầy đủ, luật làm việc, lịch sử từng phần. Đọc trước khi làm.
- `TIEN_TRIEN.md`: tóm tắt ngắn tiến độ, dùng để đưa cho AI khác.
- `TONG_HOP_TINH_NANG.md`: tình trạng từng hệ thống game.
- `MASTER_LOCK.md`: master nhân vật, không sửa.
- `game/`: bản game. `nguon/`: nguồn asset. `cong_cu/`: công cụ tạo và kiểm thử.
